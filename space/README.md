# Obelus

Paste a contract extract, choose up to three clauses, and Obelus returns the exact passages, each checked to exist word for word in your text.

It highlights passages for a human reviewer. It is not legal advice.

Source code, evaluation on 510 expert-labelled contracts, and the tests: https://github.com/Vamsi-Kattera/Obelus
